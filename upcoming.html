CURATOR Planning Record

Upcoming Changes

Updated On: September 6, 2026 at 7:24 PM EDT

Planning After v2.0.0-beta.4

These improvements are currently planned after v2.0.0-beta.4. Development is still underway, so the final list and release timing may change.

Deferred work is tracked separately. Open deferred items and unproven cases are not promised content for the next release. OHC record closures recognize their stated historical scope; they add no release candidate or new runtime proof.

MAME support in myOrganizer: CURATOR is a VERY EARLY, experimental implementation. It must NOT be relied upon as a proven means of organizing MAME sets. Continue using clrmame as the definitive MAME ROM manager. Individual MAME fixes below do not establish general MAME readiness.

Adding

  • Adding paginated startup README navigation that fits the visible console, keeps related text together where possible, and requests final acceptance only after the last page has been read.

Changing

  • Removing the CURATOR-created Atari 8-bit Family Atarimania GameBase 2021 DAT, its application-specific recognition text, release inclusion, and guide recommendations because its source-to-member derivation is not verified.

Fixing

  • Fixing duplicate review publication ordering so shared input remains available for every required output.
  • Fixing unmatched CHD and raw CDI review plans to use hashes of the actual physical files.
  • Fixing empty permanent collection publication and Reporting Standard/FullAudit handling, with populated-collection regression proof.
  • Fixing final output and ZIP member naming to use authoritative DAT filenames and extensions while retaining set titles separately.
  • Fixing shared-content ZIP publication to copy compressed members with each required filename, retain distinct definition memberships, and remove artificial Definitions routing. Same-content destination collisions, including capitalization-only member-name differences, will produce independently named duplicate-review artifacts through the established NeedsAttention hierarchy; differing physical layouts still fail closed.
  • Fixing repeated company/platform names, source labels in categories, and duplicated format routing in output paths.
  • Fixing incomplete publication packages being counted as complete and correcting physical-content evidence for preserved unmatched review files.
  • Fixing distinct DAT sets being lost when they share files or names. Sets will remain separate whenever their complete definitions differ; only definitions identical in every way may be deduplicated.
  • Fixing shared physical output accounting so distinct complete definitions retain independent memberships. Changed-input APPEND conflicts remain unproven.
  • Fixing collection reports incorrectly counting one set's output as another set's coverage when the sets share content.
  • Fixing experimental MAME machine-set handling to preserve SPLIT ownership of parent, clone, BIOS, and device files and flag missing required dependencies.
  • Fixing file-size interpretation for supported experimental MAME software-list load operations so undersized files are not accepted as complete.
