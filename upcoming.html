CURATOR Planning Announcement

Planned Changes for Next Release

Planning Record Only

These are possible upcoming changes for a future CURATOR release. They are not live, released, promised, or guaranteed. Inclusion here must not be interpreted as evidence that any item is completed, approved for release, or certain to be included in the next release. Final release contents must be established from the implementation, validation evidence, authorized release scope, and release package actually published at that time.

Adding

  • Adding support for decoding CDI, NRG, and MDF/MDS images through bundled Aaru libraries while preserving original sources.
  • Adding content-authoritative Redump CUE resolution for supported optical sets.
  • Adding exact collector-facing routing for Sega CD 32X sets without changing DAT platform authority.
  • Adding a Stage 10 output-wide receipt manifest and deterministic Append verification.

Changing

  • Changing Stage 5 to record Size, CRC32, SHA-1, and CUE custody for prepared files.
  • Changing Stage 5 to perform bounded parallel CHD extraction.
  • Changing Stage 6 to reuse prepared hashes and resolve optical authority strictly from content.
  • Changing Stage 3 to use cached hashes, batched comparison serialization, indexed reconciliation, and guarded company-summary reuse.
  • Changing Stage 9 to publish the complete physical-output execution contract and Stage 10 to consume it directly.
  • Changing TaskBars to use deterministic numeric progress and suppress stale or regressive frames.
  • Changing the Core API handbook to document 148 interfaces.

Fixing

  • Fixing duplicate sources satisfying multiple optical memberships.
  • Fixing ZIP- and loose-origin CUE repair.
  • Fixing filename-based CHD authority scoring.
  • Fixing configured non-set files (.txt, .exe, .dll, and .bat) entering Needs Attention output.
  • Fixing authoritative Jaguar CD CUE handling.
  • Fixing Gateway folder-path presentation.
  • Fixing Core build identities and stale project documentation.

Continuing Limitations

  • Continuing investigation of Reporting classifying the root receipt manifest as unmanifested content (DEFERRED-053).
  • Continuing the deferred Stage 3 and Stage 5 progress-presentation trace audit (DEFERRED-055).
