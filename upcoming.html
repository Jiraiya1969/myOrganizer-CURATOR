CURATOR Planning Record

Planned Changes for Next Release

Updated On: October 15, 2026 at 7:10 PM EDT

What We're Working On

These are the improvements currently planned for the next CURATOR release. Development is still underway, so the final list may change before release.

CURATOR v2.5.0-beta.1 remains the current public release.

Changing

  • Nested archive preparation reuses the extracted container after processing its contents, verifying its bytes and timestamp before retaining it in the workspace instead of extracting it again.
  • CHD preparation starts the next queued image whenever a worker becomes available, while preserving configured concurrency, result order and recovery behavior.
  • Scan Preparation records original and headerless file identities and creates headerless copies during copying and extraction; Matching verifies and reuses the prepared copies while preserving original bytes and raw-match priority. Missing or stale preparation evidence requires resuming Scan Preparation before Matching. Header normalization uses inclusive whole-file limits of 1,048,704 bytes for Atari 7800, 2,097,216 for Lynx, 134,218,256 for NES and 16,777,728 for SNES; larger files keep their original identity.
  • Supported CDI images use deferred track processing: Stage 5 fingerprints the source during decoding and hashes decoded tracks, avoiding a separate full-source preparation read. Track files are written only when output needs them. CDI images with external CD-TEXT retain their original container instead of publishing converted tracks.
  • Stages 1–10 and Reporting now resolve application information through database views over ingestion repositories. Stage 1–8 intermediate JSON files and their output templates are retired.
  • A complete clean restart is required. Move previous database and generated runtime state out of the active folders and rebuild from original inputs; existing databases are not migrated. Database schema remains 26.
  • Admin, End User and Quick Start guides now explain the required clean restart, database-backed stage information and retired Stage 1–8 intermediate outputs.
