CURATOR Planning Record

Upcoming Changes

Updated On: September 8, 2026 at 7:32 PM EDT

Planning After v2.0.0-beta.4

These improvements are currently planned after v2.0.0-beta.4. Development is still underway, so the final list and release timing may change.

MAME support in myOrganizer: CURATOR is a VERY EARLY, experimental implementation. It must NOT be relied upon as a proven means of organizing MAME sets. Continue using clrmame as the definitive MAME ROM manager.

Every BETA release requires a clean run. Databases, saved run state, and output plans from earlier BETA releases are not backward compatible.

Adding

  • Adding separate ZIPs for supported disk and tape images, with each file keeping its DAT filename. When a required file is missing, the available images go into separate ZIPs under NeedsAttention and the set remains incomplete.
  • Adding startup README pages that fit the console window, with final acceptance requested after the last page.

Changing

  • Changing authority preference so supplemental A8P follows Atarimania, with MAME software lists following A8P and preceding Other.
  • Removing the two Atari 2600 HyperList files from the recommended DAT sources.
  • Removing the bundled CURATOR-created Atari 8-bit Family Atarimania GameBase 2021 DAT because its file information could not be verified against its source.

Fixing

  • Updating the administrator, user, quick-start and API guides for the current implementation and its remaining limitations.
  • Fixing long delays during collection completeness checks and adding clearer progress announcements.
  • Fixing long delays when Organizer finishes publishing the collection.
  • Reducing unnecessary work while Organizer processes each output.
  • Fixing MAME software-list set titles to use their descriptions instead of abbreviated software identifiers.
  • Fixing excessive per-file console messages in Completeness and Organizer while retaining their details in stage logs.
  • Fixing publication ZIP and incomplete publication folder names to use the DAT's set name.
  • Fixing detection of DolphinTool at the configured location.
  • Fixing completeness reports so a missing or incorrectly sized required output prevents the set from being counted as complete.
  • Fixing generated GameBase set names by removing added ID suffixes and trailing spaces.
  • Fixing Atari 5200 DAT entries so alternative versions are separate sets.
  • Fixing Atari Lynx DAT requirements to exclude readme files.
  • Fixing missing Atari ST Automation and D-Bug entries in the bundled DAT.
  • Fixing duplicate handling so a shared source file remains available for every required output.
  • Fixing file verification information for unmatched CHD and CDI files sent for review.
  • Fixing processing and reporting when no files qualify for the permanent collection.
  • Fixing output filenames and filenames inside ZIPs to follow the DAT while keeping set titles separate.
  • Improving ZIP output so shared files retain the filenames required by each set, without adding unnecessary Definitions folders. Conflicting outputs are kept separately under NeedsAttention when supported; incompatible layouts are rejected rather than overwritten. Capitalization-only member-name collisions remain unresolved and can credit a set whose exact filename was not published.
  • Fixing repeated company and platform names, source labels, and duplicated format folders in output paths.
  • Fixing incomplete publication packages being counted as complete.
  • Fixing distinct DAT sets being lost when they share files or names. Sets remain separate whenever their complete definitions differ; only definitions identical in every way may be deduplicated.
  • Fixing collection reports to count each fulfilled DAT set correctly when files are shared between sets.
  • Fixing experimental MAME SPLIT handling to keep parent, clone, BIOS, and device files with their required sets and flag missing dependencies.
  • Fixing experimental MAME software-list file-size checks so undersized files are not accepted as complete.
